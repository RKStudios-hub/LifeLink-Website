Common questions

A few things to know about the current version.

What is LifeLink?

LifeLink is a hospital directory that helps you search for hospitals, check their details and find them on a map.

Can I use it without internet?

The saved hospital directory can be used offline. Map and route features may need an internet connection.

Is LifeLink free?

Yes, the app is free to download and use.

How do I install it?

On Android, download and install the APK. You can also open the web version and use your browser's "Add to Home Screen" option.

Does LifeLink use my location?

Nearby search can use your location if you allow it. You can also choose a location manually.

Can I use it to make medical decisions?

No. LifeLink is a directory and does not replace medical advice or emergency services. Hospital information may not always be current, so confirm details with the hospital. For emergencies in India, call 108.

What is the app built with?

LifeLink uses HTML, CSS and JavaScript. The map uses Leaflet and OpenStreetMap, and routes use OSRM.

What might be added later?

Possible additions include verified blood donor information, hospital updates, emergency alerts, voice search and more language options.

A quick note before you install

Android apps downloaded from a website can show a security prompt. Here’s what to do:

1. Check the browser prompt

Your browser may flag an APK from a website. If you want to continue, choose “Keep” or “Download anyway.” The wording can vary.

2. Open the downloaded APK

When it finishes, tap LifeLink.apk. If Android asks, choose Package Installer, then tap Install.
